## Execution Blueprint

### 1. Types & Persistent Billing Engine
- Create `src/types/clientBilling.ts`:
  - `PaymentMethod`: `'CBE' | 'Awash' | 'Abyssinia' | 'Telebirr' | 'Cheque' | 'Cash Receipt'`.
  - `InvoiceStatus`: `'Paid' | 'Partially Paid' | 'Pending' | 'Overdue'`.
  - `ClientPaymentRecord`:
    - `id`: string.
    - `invoiceId`: string.
    - `siteId`: string.
    - `siteName`: string.
    - `paymentDate`: string.
    - `amountPaidETB`: number.
    - `paymentMethod`: `PaymentMethod`.
    - `referenceNumber`: string (e.g., CBE transaction ID, cheque number).
    - `withholdingTaxCertificateNumber`?: string.
    - `withholdingTaxAmountETB`?: number.
    - `depositedBy`: string.
    - `notes`?: string.
    - `recordedAt`: string.
  - `ClientInvoice`:
    - `id`: string.
    - `invoiceNumber`: string (e.g., `INV-2026-10-CBE01`).
    - `siteId`: string.
    - `siteName`: string.
    - `clientOrganization`: string.
    - `division`: `'Security' | 'Cleaning' | 'Combined'`.
    - `billingPeriod`: string (e.g., `Tikimt 2017 / October 2026`).
    - `issueDate`: string.
    - `dueDate`: string.
    - `guardCount`: number; `guardRateETB`: number;
    - `cleanerCount`: number; `cleanerRateETB`: number;
    - `subtotalETB`: number;
    - `vatAmountETB`: number (15%);
    - `totalAmountETB`: number;
    - `amountPaidETB`: number;
    - `withholdingTaxCreditETB`: number (2%);
    - `remainingBalanceETB`: number;
    - `status`: `InvoiceStatus`;
    - `payments`: `ClientPaymentRecord[]`.
  - Strict line budget: $\le 100$ lines.

- Create `src/data/mockClientBilling.ts` and `src/utils/clientBillingStorage.ts`:
  - Seed dataset with realistic monthly invoices for all 14 commercial client sites (CBE Tower, Ethiopian Airlines Cargo Terminal, Hyatt Regency, St. Paul's Hospital, Bole Medhanialem, CMC Plaza, etc.).
  - Realistic statuses: `Paid`, `Partially Paid`, `Overdue` (e.g. Addis Commercial Center overdue 60 days for ETB 420,000 to match existing alert text), and `Pending`.
  - `generateMonthlyInvoices(sites: ClientSite[]): ClientInvoice[]`.
  - `loadClientInvoices(): ClientInvoice[]` and `saveClientInvoices(invoices: ClientInvoice[])`.
  - `recordInvoicePayment(invoiceId: string, payment: Omit<ClientPaymentRecord, 'id' | 'recordedAt'>): ClientInvoice`.
  - Strict line budget: $\le 200$ lines.

### 2. Interactive Payment Collection Modal
- Create `src/components/finance/SitePaymentCollectionModal.tsx`:
  - Receives `invoice: ClientInvoice | null`, `isOpen: boolean`, `onClose: () => void`, and `onPaymentRecorded: (updated: ClientInvoice) => void`.
  - Displays invoice overview card: Site name, Invoice #, Total Invoiced, Prior Payments, Current Remaining Balance.
  - Interactive collection form:
    - Payment Date picker (defaults to today).
    - Payment Amount input (ETB) with quick buttons: "Full Balance" and "Half Balance".
    - Bank / Channel dropdown: `Commercial Bank of Ethiopia (CBE)`, `Awash Bank`, `Bank of Abyssinia`, `Telebirr`, `Cheque / Direct Draft`.
    - Transaction Slip / Reference Number input (required for auditability).
    - 2% Withholding Tax Credit checkbox:
      - When checked, auto-calculates 2% of subtotal: `subtotalETB * 0.02`.
      - Prompts for Withholding Tax Certificate Number.
      - Automatically credits withholding amount toward the invoice total.
    - Deposited By & Internal Notes input.
  - Live calculation box:
    - $\text{Net Cash} = \text{Amount Paid}$.
    - $\text{Tax Credit} = \text{Withholding Amount}$.
    - $\text{New Remaining Balance} = \text{Current Balance} - (\text{Amount Paid} + \text{Withholding Amount})$.
  - On submit: calls `recordInvoicePayment`, logs audit entry, triggers success toast, and closes modal.
  - Strict line budget: $\le 220$ lines.

    - Text search by Site Name, Client Organization, or Invoice #.
    - Division filter: `All Divisions`, `Security Services`, `Cleaning Services`.

  - High-density tabular ledger:
    - Site & Organization.
    - Invoice Number & Billing Period.
    - Total Invoiced (ETB, font-mono tabular-nums).
    - Amount Collected & Withholding Credit (ETB).
    - Outstanding Balance (ETB, color-coded: emerald if 0, rose if overdue).
    - Due Date & Aging Badge (`On Time`, `Due Soon`, `Overdue 30d`, `Overdue 60d+`).
    - Action button: `💰 Record Payment` (launches `SitePaymentCollectionModal`).
  - Strict line budget: $\le 240$ lines.
