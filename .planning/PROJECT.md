# HAB Business PLC — Integrated ERP System

## What This Is
Enterprise Human Resource Management, Client Site Workforce Deployment, Payroll, and 3D Warehouse ERP for Security and Cleaning Services in Ethiopia. Built with React 19, TypeScript, Vite, Tailwind CSS, Lucide icons, and bilingual Amharic/English internationalization.

## Core Value
Streamlined workforce deployment, automated biometric attendance & payroll processing, and multi-facility operational control with high-legibility enterprise ergonomics.
