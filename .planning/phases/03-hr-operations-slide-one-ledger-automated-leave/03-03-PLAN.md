<title>Refactor LeaveManagementView with Request & Available tabs and automated deductions</title>
<instruction>
Update `src/components/LeaveManagementView.tsx` (staying under 250 lines):
- Split the interface into two clear primary views/tabs:
  1. `Request`:
     - Displays all leave applications (Pending, Approved, Rejected).
     - Allows submitting new leave requests specifying employee, leave type (Annual, Sick, Compassionate), start date, end date, and total days.

  - Show warning if requested days exceed remaining balance.
